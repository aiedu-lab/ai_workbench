# Prompt: Tower of Hanoi — Define Test Suite Structure

## Context

The class scaffold in `src/` has been generated by
`toh_problem_prompt.md`. Four skeleton classes exist with
`raise NotImplementedError` bodies. Two utilities
(`ascii_renderer.py`, `step_writer.py`) are fully implemented.

---

## Objective

Produce the **test suite skeleton** — one test file per class
plus an integration test file. Output stub files only: test
class names, test method names, and `raise NotImplementedError`
bodies. Do not write any assertions yet.

Also produce `src/tests/conftest.py` that adds `src/` to
`sys.path` so `pytest tests/` works without packaging.

---

## Test Requirements

Use the table below as the authoritative specification. Each row
names the file and what each test method must eventually assert.
This table drives the method names you generate.

| File | Must cover |
|---|---|
| `test_disc.py` | valid size; zero/negative `ValueError`; `==`; `<` |
| `test_tower.py` | construction; `peek` non-destructive; `pop` on empty raises; illegal `push` raises; `as_size_list`; `display` produces output |
| `test_move.py` | not solved at start; `next` True while moves remain; `next` False when done; Tower[2] holds all discs; move count = 2ᴺ−1 |
| `test_orchestrator.py` | initial tower state; Tower[2] full after `run()`; Tower[0]/[1] empty; step file non-empty; move count via `## Step` heading count |
| `test_integration.py` | parametrized N=1,2,3; correct final state; correct move count; ordering invariant — no tower ever has a larger disc above a smaller one at any intermediate step |

---

## Style Rules

- Test class names: `TestXxxYyy` convention.
- One test class per logical group (e.g. `TestDiscConstruction`,
  `TestDiscComparisons`).
- Every method body: exactly `raise NotImplementedError`.
- 2-space indentation; line length ≤ 79 characters.

---

## Output

Return one file per bullet, all under `src/tests/`:

- `src/tests/conftest.py`
- `src/tests/test_disc.py`
- `src/tests/test_tower.py`
- `src/tests/test_move.py`
- `src/tests/test_orchestrator.py`
- `src/tests/test_integration.py`
